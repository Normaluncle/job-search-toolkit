Remote Job Salary Data as CSV

Two remote job boards publish salary information in a usable form: Himalayas (salary range, currency, period and seniority) and Remote OK (salary range in USD, plus tech tags). These two Apify Actors export those listings as rows, so you can filter and compare salaries in a spreadsheet or pandas.

Himalayas Remote Jobs Scraper

Open on Apify

Input:

{ "keywords": "python", "salaryRequired": true, "maxJobs": 100 }

Output fields: title, companyName, employmentType, seniority, minSalary, maxSalary, currency, salaryPeriod, isWorldwide, publishedAt, url.

Use it when seniority matters, or when you need to know whether a role is open worldwide (isWorldwide).

Remote OK Jobs Scraper

Open on Apify

Input:

{ "tags": ["python", "react"], "salaryRequired": true, "maxJobs": 100 }

Output fields: title, company, location, tags, salaryMinUsd, salaryMaxUsd, publishedAt, url.

Use it when you want everything already in USD and filterable by tech tags.

A note on comparing salaries

Himalayas listings use different currencies and pay periods. Filter on currency and salaryPeriod before you compare numbers, rather than assuming everything is yearly USD.

Price

Both Actors are pay per result: $0.80 per 1,000 jobs.
