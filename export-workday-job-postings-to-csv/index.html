Export Workday Job Postings to CSV

Many large companies host their careers page on Workday (*.myworkdayjobs.com). The pages render with JavaScript, each company lives on its own subdomain, and there's no export button. The Workday Jobs Scraper on Apify turns those listings into rows you can download.

Input

Give it one or more Workday career site URLs, an optional search term, and a limit per site:

{
  "careerSiteUrls": ["https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite"],
  "searchText": "data",
  "maxJobsPerSite": 100
}

Output fields

Field What it is
title Job title
company Employer
location Location as listed
country Country
timeType Full time / part time
postedOn Posting label as shown on the site
postedDate Posting date
jobId Workday job ID
url Direct link to the posting

When the run finishes, export the dataset as CSV, JSON or Excel from Apify, or read it with the Apify API.

With details on (the default), postedDate is the job's real start date from Workday, so a "Posted 30+ Days Ago" job still gets its exact date (for example 2026-07-28 in the first row).

What people use it for

  • Watching target companies: schedule a daily run and compare jobIds to spot new openings.
  • Niche job boards: filter by country or timeType and publish the rest.
  • Hiring trends: count postings per company or location over time.
