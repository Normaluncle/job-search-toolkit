## The 4 minimal-tracking rules

1. **One status per application.** Every application sits in exactly one stage. If you can't say which stage a company is in, you haven't really followed up.
2. **Company, role, next action date.** "Waiting to hear back" isn't progress. A follow-up without a date usually never happens.
3. **Two follow-ups, then close it.** After two follow-ups with no answer, the next status can only be withdrawn or declined.
4. **A weekly check of three numbers.** New applications this week, companies at the interview stage, and applications that haven't moved in 7+ days. Every stale one gets a decision.
